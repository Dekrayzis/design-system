## Spacing

A 4px grid. Use `--ds-space-{n}` or the `gap` prop on `Stack`.

<div style={{ display: 'grid', gap: 8 }}>
  {[1, 2, 3, 4, 5, 6, 8, 10, 12].map((n) => (
    <div key={n} style={{ display: 'flex', alignItems: 'center', gap: 16 }}>
      <code style={{ width: 120 }}>--ds-space-{n}</code>
      <div style={{ width: `var(--ds-space-${n})`, height: 16, background: 'var(--ds-color-accent)', borderRadius: 2 }} />
      <span style={{ color: 'var(--ds-color-text-muted)', fontSize: 14 }}>{n * 4}px</span>
    </div>
  ))}
</div>
